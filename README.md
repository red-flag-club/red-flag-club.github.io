# red-flag-club.github.io

The published Red Flag Club site: https://red-flag-club.github.io

**This repository is written by a bot. Don't edit it, and don't open pull
requests here.** Every file is rebuilt from
[red-flag-club/red-flag-club](https://github.com/red-flag-club/red-flag-club)
(`web/` for the pages, the daily scan for `data/*.json`) after each trading
session, and the approved stories come from
[red-flag-club/stories](https://github.com/red-flag-club/stories).

- **What:** risk lists, look-ups, stories, quiz, assistant and victim help for
  people facing pump-and-dump groups.
- **Why:** the warning has to reach people before the pitch, for free, with
  no tracking.
- **How:** a static site on GitHub Pages; no cookies, no trackers, no external
  scripts. Data files contain verdicts, flags and percentages, not prices.

Found a problem? [Open an issue in the code repo](https://github.com/red-flag-club/red-flag-club/issues/new/choose).
